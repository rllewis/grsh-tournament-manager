REVISION 2 - SLUG CONFLICT FIX ATTEMPT (URL REWRITE HOOK)
Date: 2026-05-29
File: grsh-tournament-manager.php (~313 lines)
--------------------------------------------------------------------------------

ISSUE IDENTIFIED:
  Sidebar links rendering as bare slugs (e.g. grsht.com/wp-admin/grsh-players)
  instead of full admin.php?page= URLs. Dashboard worked, all other pages
  failed with "This page doesn't seem to exist."

ROOT CAUSE THEORY:
  SportsPress plugin registers 'players', 'teams', 'staff' as custom post type
  slugs. With Post Name permalinks active, WordPress was routing 'grsh-players'
  to the frontend instead of the admin.

ADDED:
  - URL rewrite hook on admin_menu priority 9999
  - Hook iterates $submenu['grsh-dashboard'] and rewrites bare slugs
    matching 'grsh-*' pattern to 'admin.php?page=grsh-*'
  - Comment block explaining SportsPress conflict rationale

CHANGED:
  - None (slugs and capabilities unchanged)

RESULT:
  Did not fix the issue. Sidebar links still failed.

--------------------------------------------------------------------------------
ROOT CAUSE DISCOVERED - NOT A PLUGIN ISSUE
Date: 2026-05-29 22:50 PT
--------------------------------------------------------------------------------

DIAGNOSIS:
  After exhaustive plugin debugging, discovered that even the basic
  WordPress admin URL grsht.com/wp-admin/ returns "This page doesn't
  seem to exist" — meaning the issue is NOT with the GRSH plugin at all.

ACTUAL CAUSE:
  WPS Hide Login plugin is intercepting ALL /wp-admin/ URLs and redirecting
  unrecognised admin page requests to https://grsht.com/404/.

WPS HIDE LOGIN CONFIGURATION:
  Login URL:       https://grsht.com/manage/
  Redirection URL: https://grsht.com/404/

PROPOSED FIX (pending verification):
  Option A: Clear the Redirection URL field in WPS Hide Login settings
  Option B: Deactivate WPS Hide Login plugin entirely
  Option C: Configure WPS Hide Login compatibility mode if available
  Option D: Add GRSH admin page slugs to WPS Hide Login allowlist

STATUS:
  Pending user action to test WPS Hide Login configuration changes.
  GRSH plugin code itself is correct and complete.
